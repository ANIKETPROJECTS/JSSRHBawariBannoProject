# Running the project on Replit

This is a frontend-only TanStack Start, React, and Vite application. It uses
Bun with the checked-in `bun.lock` file for repeatable dependency installs.

## Development preview

The Replit workflow runs:

```sh
bun run dev -- --host 0.0.0.0 --port 5000
```

Open the web preview once the workflow is running. No secrets, database, or
external services are required for the current storefront demo.
